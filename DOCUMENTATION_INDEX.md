## 🎨 Diagram Resources

### Viewing Mermaid Diagrams

**GitHub:**
- Diagrams render automatically in markdown files
- Click to zoom
- No installation needed

**VS Code:**
1. Install: [Markdown Preview Mermaid Support](https://marketplace.visualstudio.com/items?itemName=bierner.markdown-mermaid)
2. Open markdown file
3. Press `Cmd+Shift+V` (macOS) or `Ctrl+Shift+V` (Windows)

**Obsidian:**
- Built-in Mermaid support
- Open any markdown file with diagrams

**Online Editor:**
- [https://mermaid.live](https://mermaid.live) - Edit and export diagrams

### Exporting Diagrams

**As PNG:**
```bash
mmdc -i diagram.mmd -o diagram.png -w 2000 -b transparent
```

**As SVG:**
```bash
mmdc -i diagram.mmd -o diagram.svg -b transparent
```

See [ARCHITECTURE_DIAGRAMS_README.md](ARCHITECTURE_DIAGRAMS_README.md) for details.

## 🤝 Contributing to Documentation

### When to Update Documentation

**Update when you:**
- Add new features
- Change architecture
- Add new tools or providers
- Fix bugs that affect usage
- Discover better practices

### Documentation Standards

**For guides:**
- Include table of contents
- Add troubleshooting section
- Provide code examples
- Use clear section headers
- Include links to related docs

**For diagrams:**
- Use Mermaid syntax
- Keep diagrams focused
- Add descriptive titles
- Use consistent colors
- Test rendering on GitHub

**For quick references:**
- Keep under 5 pages
- Focus on most common tasks
- Use tables for comparisons
- Include command examples
- Link to detailed guides
